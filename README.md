## ✨ Overview

A frontend recreation of Facebook's familiar login page, featuring a minimalist design, responsive layout, and interactive button hover effects.

Built to practice HTML5, CSS3, Flexbox, and responsive web design.

## 🚀 Features

- 🔐 Email and password input fields
- 🎨 Facebook-inspired colors and styling
- 🖱️ Interactive button hover effects
- 📱 Responsive layout for smaller screens
- 💎 Rounded corners and subtle shadows
- 🧩 Simple, clean HTML and CSS

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **Flexbox** — Content alignment
- **Media Queries** — Responsive design
